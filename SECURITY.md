# Security policy

Do not report security vulnerabilities in public issues.

Use [GitHub's private vulnerability reporting](https://github.com/Jetplugins/intellij-rust-pro-plugin/security/advisories/new) to share the affected Rust Pro version, impact, reproduction steps and supporting material privately with the maintainers.

Include the IDE and full build, operating system, Rust toolchain and relevant analyzer, debugger or remote-environment versions. Remove credentials, license keys, proprietary source code, personal information and unrelated confidential information from reports and attachments.
